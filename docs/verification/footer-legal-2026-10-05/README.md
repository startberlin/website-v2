Footer and legal-page verification, 5 October 2026. The implementation uses the current START Munich footer and legal-page layout as a visual reference, with the existing V2 Cyan and Avenir tokens. Berlin social links and all legacy legal text come from `website-raw`. The raw repository was read only.

`check:design`, Astro typecheck and an isolated production build pass. The typecheck covers 59 files with zero errors, zero warnings and three existing deprecation hints. All 47 existing Jobboard tests pass. Tracked `dist/` and both lockfiles remain unchanged. See [code checks](code-checks.json), [build log](build.log) and [typecheck log](typecheck.log).

[108 browser views](browser-views.json) cover Home, Members, Join, Jobs, Post a role, Jobs privacy, Legal Notice, Privacy Policy and the Jobs detail unavailable state. Widths are 320, 390, 640, 767, 768, 1023, 1024, 1280, 1440 and 1920 CSS pixels, plus 844 × 390 phone landscape and 1024 × 768 tablet landscape. Every recorded viewport was checked against the actual browser dimensions. All views have one main, one H1 and one footer, no horizontal overflow and no page errors. Footer targets are at least 44 × 44 pixels, external social links have accessible names and safe new-tab attributes, and desktop legal links sit centrally.

[Keyboard checks](browser-interactions.json) cover focus, Enter navigation, current-page highlighting, the general/jobs privacy round trip, mobile focus wrapping, Escape and desktop resizing. The open mobile menu makes main and footer inert and removes those attributes on close. Donate is disabled, described by visible "Coming soon" and skipped during normal tab navigation. [Accessibility semantics](screen-reader-semantics.json) and the [native accessibility tree](legal-accessibility-tree.txt) confirm names, heading structure and disabled/decorative states. [Seven contrast samples](contrast.json) pass, with the lowest ratio 7.23:1. The loaded reduced-motion CSS disables footer transitions. No operating-system preference change or speech-output audit was performed, and this is not a claim of complete site-wide accessibility conformance.

[Fourteen text-size checks](text-zoom.json) use the actual legal pages with a temporary global root font of 32 pixels, twice the default 16. Both pages pass at 320, 390, 768, 1024, 1280, 1440 and 1920 pixels. This exercises text scaling and reflow; it does not emulate a browser's full-page zoom menu. Initial failures at 320 in the header and 768 in the footer are recorded in [the diagnostic results](text-zoom-before.json). Constraining the logo and letting footer areas wrap fixes them. Temporary routes were removed before the final build; their port-4340 server was stopped.

[HTTP checks](http-checks.json) confirm the new legal pages return 200 and the legacy `/legal/legal-notice.html` and `/legal/privacy.html` URLs return 301 to their clean destinations, followed by 200. The built body copy matches the source after whitespace, quotes and heading-case normalization. [Migration provenance](content-migration.json) records source hashes and all 102 source blocks. The general privacy page additionally links to the existing Jobboard notice. Jobs listing/detail intentionally return their controlled 503 unavailable state because no Cockpit credentials were supplied. Their footer still renders correctly. No external form, company submission or donation was sent.

[Seven external destinations](external-links.json) returned 200. The inherited ODR URL redirects to an official closure notice. The [European Commission](https://consumer-redress.ec.europa.eu/site-relocation_en) states that the platform closed on 20 July 2025. The requested source text also still identifies Webflow as the host. These copied statements require reconciliation before release, as recorded in [content notes](content-notes.json). Donate stays pending until its actual destination exists.

The fresh built preview is available locally at `http://127.0.0.1:4338`. No production deployment was performed. Preview command: `HOST=127.0.0.1 PORT=4338 PUBLIC_SITE_URL=http://127.0.0.1:4338 node .astro/footer-build/server/entry.mjs`.
